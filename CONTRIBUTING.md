# Contributing to super-intelligence-force-brief

This repository holds a policy brief: Slid Phi Labs' submission for the
Super Intelligence Force's 120-day report (EO 2026-09-29). It is a
Markdown document, not a software project — there is no build and no test
suite to run.

## What counts as a contribution

- Factual corrections (wrong claims, stale numbers, broken links)
- Clearer wording that keeps the brief's voice: plain, checkable, no lobbying jargon
- Additional sources or evidence behind a claim

This brief argues a position. Edits that change its stance should be
discussed in an issue first, not just filed as a PR.

## Ground rules

- Every factual claim added or changed needs a source: a link or citation
  in the PR description or the text itself.
- Numbers must be verified against the underlying work (case counts, byte
  counts, dates) before the PR goes up.
- Never add secrets, keys, tokens, or internal identifiers.
- Check every link you add or touch.

## How to propose a change

1. Open an issue first for anything that changes the brief's position.
2. Make the edit.
3. Open a pull request using the PR template (the checklist is the review bar).

## Licensing

This repository currently declares no license. Until one is declared, all
rights are reserved by the author and contributions are accepted only on
the understanding that the maintainer may license the work (including your
contribution) under whatever terms they choose. If that is a problem, open
an issue to discuss it before contributing.
